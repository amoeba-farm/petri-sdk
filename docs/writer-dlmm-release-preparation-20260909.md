# Writer/DLMM SDK release preparation

The release coordinator owns publication, signing and deployment. The SDK component prepares one coherent local change and consumes the actual native publication pin and finalized deployment evidence. Planned slots, epochs and source commits are not release evidence.

## Maintained commands and order

1. `node scripts/adopt-published-native.mjs <coordinator-publication-input.json>` validates every packaged native byte against the selected immutable Git blob before staging package, Cargo and hidden mirror bindings. Input fields are `schemaVersion:1`, `sourceCommit`, `sourceRepository`, `archive`, and `archiveSha256`. Local paths are read as inputs and are not copied into the portable publication record. This command does not promote the current runtime release.
2. Use the pinned npm 10.9.8 for `install --ignore-scripts --no-audit --no-fund`, and Cargo to resolve only the changed native Git dependency. No shared pnpm store hydration or installation-layout substitution is appropriate.
3. Once the coordinator supplies finalized evidence, run `node scripts/promote-writer-dlmm-release.mjs <coordinator-finalized-release-input.json>`. Inputs are `schemaVersion:1`, the actual `sourceCommit` and `artifactSourceCommit`, `sbfArtifact`, and `deploymentEvidence`. The latter has `genesis` (or `genesisHash`), `slot` (or `contextSlot`), `observedAt`, and the four `accounts` entries with `address`, `owner`, `executable`, and `dataGzipBase64` or `dataBase64`. The command compares actual ELF, allocated padding, account identities, active gate and controller bytes before writing the new descriptor, runtime records, transport hashes and current fixture bindings. It retains the precise same-checkout/two-target build scope and preserves old evidence. The old scoped updater/capture/test-binding scripts contain historical inputs and must not run unchanged against this release.
4. Run `node scripts/refresh-package-build-identity.mjs` after dependency locks and release inputs settle, then emit final production outputs with `npm run build`. The source inventory excludes its own descriptor and the derived release-train JSON to avoid a digest cycle; tracked TypeScript and all underlying release inputs remain covered. `node scripts/finalize-scoped-release-indexes.mjs` regenerates derived train/writer-tag indexes from this final emission. Reuse the existing browser/native results where inputs are unchanged. The user selected only the two native critical tests; no additional broad test campaign is part of this deployment preparation.
5. Pack once with npm 10.9.8 and `--ignore-scripts --json`. Use `node scripts/update-release-package-measurement.mjs <npm-pack.json>` to update bounds from the real final archive. Commit the coherent source, portable evidence, lockfiles and generated output locally for the coordinator.
