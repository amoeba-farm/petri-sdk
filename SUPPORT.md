# Support

## Questions and bug reports

Use [GitHub issues](https://github.com/SPACE999978/ameba_sdk/issues) for
reproducible SDK bugs, documentation problems, and focused feature requests.
Search existing issues first.

Include:

- the `ameba-sdk` version;
- Node.js, npm, and TypeScript versions;
- the entry point and method used;
- a minimal example and the structured SDK error; and
- whether the native HTTP client, protocol builders, operator helpers, or Petri
  adapter are involved.

Remove backend credentials, wallet material, signed transaction bytes, private
URLs, personal data, and secrets before posting.

## Scope

This repository supports the TypeScript/JavaScript SDK boundary. Backend
deployment incidents, on-chain governance decisions, market-data disputes, and
Petri binary installation may require coordination with their owning Amoeba
component. The SDK does not provide trading, legal, financial, or investment
advice.

Potential vulnerabilities must be reported through
[SECURITY.md](./SECURITY.md), not a public issue.
